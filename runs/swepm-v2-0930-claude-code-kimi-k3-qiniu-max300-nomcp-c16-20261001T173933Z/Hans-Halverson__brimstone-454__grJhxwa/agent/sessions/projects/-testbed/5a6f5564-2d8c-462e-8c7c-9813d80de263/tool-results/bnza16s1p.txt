    [runtime] Fast path for creating data properties on ordinary object (#453)
    
    ## Summary
    
    The common case of adding a new data property to an ordinary object can
    be done without going through the full
    `validate_and_apply_property_descriptor`. Introduce a new
    `VirtualObject::create_data_property` which has a faster implementation
    for ordinary objects.
